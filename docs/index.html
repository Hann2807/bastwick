Bastwick Center

VPN-ядро + центр безопасности для macOS 13+ · Apple Silicon и Intel

Установка одной командой — откройте Терминал:

curl -fsSL https://raw.githubusercontent.com/<OWNER>/<REPO>/main/install.sh | zsh

Скрипт проверит систему, скачает сборку с проверкой md5 и установит в /Applications. Предупреждения Gatekeeper не будет.

Ручная установка

Скачать Bastwick-notarize-ready.zip
  • Перетащите Bastwick.app в «Программы»
  • Если macOS спросит: правый клик → «Открыть» (один раз)
  • Запустите и нажмите «Подключить» — разрешите VPN-конфигурацию

Что внутри

  • VPN — WireGuard, Always-On, kill-switch, локации с пингом
  • Web Shield — DNS-блокировка фишинга и майнинг-доменов
  • Screen Guard — монитор съёма экрана
  • Breach Monitor — проверка паролей строго локально
  • Очистка — мусор старше 30 дней

Без регистрации и подписки. Источник: GitHub — исходная страница репозитория (README) содержит те же инструкции.

Установочный скрипт открыт (install.sh в репозитории): скачивание релиза + проверка md5 + установка в /Applications.
