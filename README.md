# Bastwick Center

**VPN-ядро + центр безопасности для macOS.** WireGuard-туннель с
Always-On и kill-switch, DNS-фильтр от фишинга (Web Shield), монитор
съёма экрана, локальная проверка паролей по базам утечек — всё локально,
на вашем Mac.

- macOS 13.0+ (Ventura и новее), Apple Silicon и Intel (universal)
- Трафик шифруется WireGuard; подключается при пробуждении и смене сети
- Без регистрации, без аккаунтов, без подписки (Free)

---

## Установка одной командой (рекомендуется)

Откройте **Терминал** и вставьте:

```bash
curl -fsSL https://raw.githubusercontent.com/Hann2807/bastwick/main/install.sh | zsh
```

Скрипт сам проверит систему (macOS 13+, не виртуальная машина), скачает
проверенную по md5 сборку, установит в `/Applications` и откроет
приложение. Никаких предупреждений Gatekeeper — скачивание идёт через
curl, который не ставит кворантин.


Установочный скрипт **открыт**: [`install.sh`](./install.sh) — можно прочитать перед запуском. Он только скачивает архив релиза, проверяет md5 и устанавливает приложение в `/Applications`.

## Ручная установка

1. Скачайте `Bastwick-notarize-ready.zip` со страницы [Releases](../../releases).
2. Распакуйте и перетащите **Bastwick.app** в **Программы**.
3. Если macOS покажет предупреждение Gatekeeper: правый клик по
   приложению → **Открыть** → Открыть (один раз; это стандартная
   процедура для приложений вне App Store).
4. Запустите приложение — в меню-баре появится щит. Нажмите
   **«Подключить»** и разрешите добавление VPN-конфигурации.

## Системные требования

| | |
|---|---|
| macOS | 13.0 Ventura или новее |
| Архитектура | Apple Silicon (M1+) и Intel — universal binary |
| Права | VPN-профиль (системный запрос при первом запуске), опционально — Accessibility для Smart Setup, Full Disk Access для Breach Monitor |

## Проверка скачанного вручную (опционально)

```bash
md5 -q Bastwick-notarize-ready.zip
# должен совпасть со значением на странице релиза
```

## Что внутри

- **VPN** — WireGuard, локации с пингом, Always-On (On-Demand),
  kill-switch (весь трафик только через туннель), обход локальной сети
  для принтеров/NAS;
- **Web Shield** — DNS-блокировка фишинговых и майнинг-доменов;
- **Screen Guard** — уведомления о съёме экрана;
- **Breach Monitor** — проверка сохранённых паролей **локально**
  (ничего не отправляется наружу);
- **Очистка** — удаление мусора старше 30 дней.
